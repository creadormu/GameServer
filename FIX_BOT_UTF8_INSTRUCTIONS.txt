HOW IT WORKS:
=============

ReadUTF8File() function (from UnicodeFileIO.h):

1. Opens file as binary mode
2. Reads entire content
3. Detects UTF-8 BOM (0xEF 0xBB 0xBF) if present
4. Skips BOM
5. Returns lines as UTF-8 std::string
6. Your bot code stores UTF-8 strings
7. When bot sends to chat → UTF-8 data sent correctly!
8. Players see: "De onde você é?" ✅
