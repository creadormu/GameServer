╔══════════════════════════════════════════════════════════════════════════╗
║                           HOW IT WORKS                                   ║
╚══════════════════════════════════════════════════════════════════════════╝

1. Open "Create Multiple Bots" dialog (IA Menu → Create Multiple Bots)

2. You'll see the new "Bot Names Language:" dropdown

3. Click the dropdown to see all available languages

4. Select your preferred language (e.g., English, Chinese, etc.)

5. The names are loaded IMMEDIATELY - check the console:
   [CreateBots] Language changed to: English
   
6. Configure your other bot settings (count, level, location, etc.)

7. Click "Create Bots"

8. Bots will be created with names from your selected language!
   Example Output:
   - Spanish:  Bot0001 = Carlos23
   - English:  Bot0001 = James56  
   - Chinese:  Bot0001 = Wei42
   - Japanese: Bot0001 = Hiroshi28

╔══════════════════════════════════════════════════════════════════════════╗
║                        COMPILATION STEPS                                 ║
╚══════════════════════════════════════════════════════════════════════════╝

1. Open GameServer.sln in Visual Studio

2. Add new files to project:
   - Right-click GameServer project
   - Add → Existing Item
   - Select: NameManager.h and NameManager.cpp

3. Build Solution (F7 or Ctrl+Shift+B)

4. If you see resource.h warnings, just rebuild

5. Copy IA/ folder to your GameServer.exe directory

6. Run GameServer.exe

7. Check console for:
   [NameManager] Found 6 language(s):
     - Spanish
     - English
     - Chinese
     - Japanese
     - German
     - Fantasy-Example
   [NameManager] Loaded language: Spanish (50 male, 40 female names)

8. Open IA → Create Multiple Bots

9. You should see the Language dropdown! 🎉

╔══════════════════════════════════════════════════════════════════════════╗
║                     TROUBLESHOOTING                                      ║
╚══════════════════════════════════════════════════════════════════════════╝

❓ Language dropdown not visible?
   → Check GameServer.rc was properly updated
   → Rebuild solution (Ctrl+Shift+B)
   → Check resource.h has IDC_COMBO_LANGUAGE defined

❓ Dropdown is empty?
   → Check IA/Names/ directory exists with language folders
   → Check console for [NameManager] messages
   → Verify MaleNames.txt and FemaleNames.txt exist in language folders

❓ Names still Spanish?
   → Select language from dropdown
   → Check console: [CreateBots] Language changed to: [Language]
   → Create bots and check generated names

❓ Compiler errors?
   → Ensure NameManager.h and NameManager.cpp are in project
   → Check #include "NameManager.h" is in GameServer.cpp
   → Rebuild entire solution
