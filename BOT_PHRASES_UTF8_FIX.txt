PROBLEM IDENTIFIED:
===================

When YOU type "De onde você é?" → Works perfect ✅
When BOT reads from file → Shows symbols ❌

WHY THIS HAPPENS:
=================

The bot was reading BotPhrases.txt using:
  std::ifstream file(filename);  // ❌ Reads as ANSI, not UTF-8!

This reads the file as ANSI/ASCII instead of UTF-8!

Result:
  "você" → Becomes symbols when bot reads it
  But YOUR keyboard input → Works (uses UTF-8 protocol)

THE FIX:
========

Changed FakeOnline.cpp LoadBotPhrasesFromFile() to use:
  ReadUTF8File(filename, lines);  // ✅ Reads as UTF-8!

This function from UnicodeFileIO.h properly reads UTF-8 files!

WHAT WAS CHANGED:
=================

File: GameServer/FakeOnline.cpp
Function: LoadBotPhrasesFromFile()

OLD CODE (Line 320):
-------------------
std::ifstream file(filename);
if (!file.is_open()) { return; }

std::string line;
while (std::getline(file, line)) {
    // Process line...
}
file.close();

NEW CODE (FIXED):
-----------------
// Read file as UTF-8 to support Unicode characters
std::vector<std::string> lines;
if (!ReadUTF8File(filename, lines)) {
    LogAdd(LOG_RED, "[BotPhrases] Failed to load: %s", filename);
    return;
}
LogAdd(LOG_GREEN, "[BotPhrases] Loaded %d lines from: %s", lines.size(), filename);

for (auto& line : lines) {
    // Process line...
}

WHY THIS WORKS:
===============

ReadUTF8File() from UnicodeFileIO.h:
1. Opens file as binary
2. Detects UTF-8 BOM (if present)
3. Reads as UTF-8 encoding
4. Converts to std::string (UTF-8 internal representation)
5. Returns vector of UTF-8 strings ✅

Result:
  "De onde você é?" → Stored correctly in std::string
  Bot sends to chat → Displays correctly! ✅

ENSURE YOUR FILE IS UTF-8:
===========================

Your BotPhrases.txt file MUST be saved as UTF-8!

In Notepad++ or VS Code:
1. Open: IA/Phrases/Portuguese/BotPhrases.txt
2. Check encoding: Should show "UTF-8" or "UTF-8 with BOM"
3. If not, convert:
   - Notepad++: Encoding → Convert to UTF-8
   - VS Code: Click encoding in status bar → Save with Encoding → UTF-8

RECOMMENDED: UTF-8 with BOM
- BOM = Byte Order Mark (0xEF, 0xBB, 0xBF)
- Tells programs: "This is UTF-8!"
- Our ReadUTF8File() detects and skips BOM automatically

C++ LESSON - FILE ENCODINGS:
=============================

std::ifstream file("text.txt");           // ❌ ANSI/ASCII
   → "você" becomes "voc�" or "voc?"

ReadUTF8File("text.txt", lines);          // ✅ UTF-8
   → "você" stays "você" ✅

Windows API equivalent:
FILE* file = fopen("text.txt", "r");      // ❌ ANSI
FILE* file = _wfopen(L"text.txt", L"r");  // ✅ Wide char (UTF-16)
ReadUTF8File() → Handles UTF-8 properly   // ✅ Best!
