HOW TO CONVERT FILES TO UTF-8:
===============================

OPTION 1: Using Notepad++
--------------------------
1. Open the file: BotPhrases.txt
2. Menu → Encoding → Check if it says "UTF-8" or "ANSI"
3. If ANSI: Menu → Encoding → Convert to UTF-8 (NOT "Encode in UTF-8"!)
4. Save the file (Ctrl+S)
5. Bottom-right should now show "UTF-8" ✅

OPTION 2: Using VS Code
------------------------
1. Open the file: BotPhrases.txt
2. Bottom-right corner shows current encoding
3. Click on encoding (e.g., "ANSI", "Windows 1252")
4. Select "Save with Encoding"
5. Choose "UTF-8" (or "UTF-8 with BOM")
6. Save the file

OPTION 3: Using PowerShell (Automatic)
---------------------------------------
Get-Content "BotPhrases.txt" | Set-Content -Encoding UTF8 "BotPhrases.txt"

RECOMMENDED: UTF-8 with BOM
============================

BOM = Byte Order Mark (0xEF 0xBB 0xBF at start of file)

Benefits:
✅ Programs KNOW it's UTF-8
✅ No encoding detection needed
✅ Works everywhere (Windows, Linux, Mac)
✅ Our ReadUTF8File() detects and skips BOM automatically

In Notepad++:
- Menu → Encoding → "UTF-8-BOM" ← Use this! ⭐

VERIFY FILE ENCODING:
=====================

After converting, verify with hexdump:
- UTF-8 with BOM starts with: EF BB BF
- UTF-8 without BOM: Just text directly

Or just check in Notepad++ bottom-right corner:
- Should show "UTF-8" or "UTF-8-BOM" ✅

WHY THIS HAPPENS:
=================

Portuguese uses extended ASCII characters:
- á = 0xE1 in ANSI (Latin-1)
- á = 0xC3 0xA1 in UTF-8 (multi-byte!)

When std::ifstream reads UTF-8 file as ANSI:
- Reads 0xC3 0xA1 as TWO characters → Shows as "�"
- Wrong interpretation!

When ReadUTF8File reads UTF-8 file as UTF-8:
- Reads 0xC3 0xA1 as ONE character "á"
- Correct interpretation! ✅

C++ LESSON:
===========

Bad way (ANSI):
```cpp
std::ifstream file("phrases.txt");
std::string line;
std::getline(file, line);
// "Horário" → "Hor�rio" ❌
```

Good way (UTF-8):
```cpp
std::vector<std::string> lines;
ReadUTF8File("phrases.txt", lines);
// "Horário" → "Horário" ✅
```

ALWAYS use ReadUTF8File() for text files with special characters!
