WHY COMPOSITE PRIMARY KEYS:
============================

These tables use composite keys because:
  - One character can have MULTIPLE quests
  - Need to identify: "Which quest for which character?"

Example data:
  Name      QuestIndex
  -------   ----------
  "João"    1          ← Quest 1 for João
  "João"    2          ← Quest 2 for João
  "Maria"   1          ← Quest 1 for Maria

Primary key (Name + QuestIndex) ensures uniqueness:
  ✅ Same character can have different quests
  ✅ Same quest can be done by different characters
  ✅ No duplicate (Name, QuestIndex) combinations
