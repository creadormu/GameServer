================================================================================
                              HOW IT WORKS
================================================================================

1. SERVER STARTUP:
   - g_NameManager.Initialize() is called
   - Scans IA/Names/ directory for language folders
   - Automatically loads Spanish (or first available language)
   - Falls back to hardcoded names if no files found

2. CREATE BOTS DIALOG:
   - Displays language dropdown with available languages
   - Shows current loaded language
   - User can change language on-the-fly

3. NAME GENERATION:
   - When creating bots, calls g_NameManager.GetRandomMaleName()
   - Or g_NameManager.GetRandomFemaleName() for ELF/SUM
   - Returns random name from loaded list
   - Appends random number (10-99) to create unique bot names

4. NAME FORMAT:
   - Pattern: [Name][Number]
   - Examples: Carlos23, Maria45, Hiroshi87, Aragorn99

2. Create MaleNames.txt:

   Name1

3. Create FemaleNames.txt:

   Name3
   ...

4. Restart GameServer (or select new language in dialog)

5. Done! Your language appears in the dropdown

================================================================================
                              TECHNICAL DETAILS
================================================================================

CLASS: CNameManager
-------------------
- Singleton pattern (g_NameManager global instance)
- Dynamic std::vector storage (no fixed limits)
- Efficient random access (O(1) name lookup)
- Thread-safe name retrieval
- UTF-8 encoding support

METHODS:
--------
- Initialize()                 - Scan and load default language
- LoadLanguage(name)           - Load specific language
- GetRandomMaleName()          - Get random male name
- GetRandomFemaleName()        - Get random female name
- GetAvailableLanguageCount()  - How many languages available
- GetLanguageName(index)       - Get language name by index
- GetCurrentLanguage()         - Current loaded language name

FILE FORMAT:
-----------
- Plain text (.txt)
- UTF-8 encoding
- One name per line
- Comments: ; or #
- Empty lines ignored
- Max 31 characters per name (database limit)

DIRECTORY STRUCTURE:
-------------------
IA/Names/[Language]/MaleNames.txt
IA/Names/[Language]/FemaleNames.txt

LANGUAGE DETECTION:
------------------
- Automatic folder scanning on startup
- Case-insensitive language names
- Sorted alphabetically in dropdown
