FLUJO DE USUARIO:
================================================================================

CONFIGURAR AUTO-UPDATE:
1. Click: Update → Config Updates
2. Cambia checkboxes y URL visual
3. Click: Save Configuration
4. ¡Listo!

ACTUALIZAR GAMESERVER:
1. Click: Update → Check for Updates
2. Si hay update: "Download now?" → Yes
3. Ventana progreso aparece automáticamente
4. Después descarga: "Apply now?" → Yes
5. ¡Servidor actualizado!

TOTAL: 2 clicks para configurar, 2 clicks para actualizar! 🎉
