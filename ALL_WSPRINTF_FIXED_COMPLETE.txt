================================================================================
  WHAT WAS THE PROBLEM?
================================================================================

**wsprintf = Windows API function = ANSI only**
- Treats UTF-8 multi-byte sequences as separate ANSI characters
- "Olá" (UTF-8: [0x4F, 0x6C, 0xC3, 0xA1]) → "Ol�" (ANSI interpretation)

**sprintf_s = Standard C function = UTF-8 compatible**
- Treats strings as byte arrays (no encoding assumption)
- "Olá" (UTF-8: [0x4F, 0x6C, 0xC3, 0xA1]) → "Olá" (preserved correctly)
