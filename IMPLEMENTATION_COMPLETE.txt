   No more 30-name limit! Add as many as you want.

🌍 MULTI-LANGUAGE
   Easy switching between languages in Create Bots dialog.

📝 SIMPLE TEXT FILES
   One name per line. Edit with Notepad, VS Code, or any editor.

🔄 HOT RELOAD
   Change language without restarting server.

🎭 GENDER-AWARE
   ELF & SUM classes use female names, others use male names.

🛡️ FAILSAFE
   If files missing, automatically uses built-in Spanish names.

🌐 UTF-8 SUPPORT
   Chinese, Japanese, or any special characters work perfectly.

🚀 HOW TO USE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: COMPILE
───────────────
Add these files to your Visual Studio project:
  • GameServer/NameManager.h
  • GameServer/NameManager.cpp

Compile the GameServer.

STEP 2: DEPLOY FILES
────────────────────
Copy the IA/ folder to your GameServer directory:
  GameServer.exe
  IA/
    ├── Names/
    │   ├── Spanish/
    │   ├── English/
    │   ├── Chinese/
    │   └── ...
    └── Generated/

STEP 3: RUN SERVER
──────────────────
Start GameServer and check console:
  [NameManager] Found 5 language(s):
    - Spanish
    - English
    - Chinese
    - Japanese
    - German
  [NameManager] Loaded language: Spanish (50 male, 40 female names)

STEP 4: CREATE BOTS
───────────────────
1. Open "Create Bots" dialog
2. Select language from dropdown
3. Configure bot settings
4. Click "Create Bots"
5. Check generated files in IA/Generated/
