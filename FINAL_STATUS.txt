═══════════════════════════════════════════════════════════════════════════
                     🗺️ SAFE ZONE WANDERING (FIXED!)
═══════════════════════════════════════════════════════════════════════════

PROBLEM:
────────
Bots spawned in safe zones (Lorencia, Noria) just STAND STILL ❌

SOLUTION:
─────────
SafeZoneWander(aIndex) function:
1. Detects if bot is in safe zone
2. Picks random nearby point
3. Calculates path using CMapPath::FindPath()
4. Bot walks naturally to that point
5. Repeats → creates walking pattern!

RESULT:
───────
✅ Merchants walk around Lorencia advertising trades
✅ Friendly bots walk around greeting newbies
✅ Natural, realistic movement
✅ Uses standard MU pathfinding system

DEFINED SAFE ZONES:
───────────────────
• Map 0  - Lorencia (80-180, 80-220)
• Map 2  - Devias (180-230, 0-60)
• Map 3  - Noria (150-200, 100-160)
• Map 51 - Elveland (40-90, 180-230)
• Map 1  - Elbeland (entire map)
