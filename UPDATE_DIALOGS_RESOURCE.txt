================================================================================
INSTRUCCIONES PARA AGREGAR:
================================================================================

OPCIÓN A: Visual Studio (Recomendado)
--------------------------------------
1. Abre GameServer.sln en Visual Studio
2. En Solution Explorer → Expande "Resource Files"
3. Doble clic en "GameServer.rc"
4. En Resource View → Right-click "Dialog" → Add Resource → Dialog
5. Copia y pega el código de arriba en modo texto (View → Code)
6. O usa el editor visual para crear los controles

OPCIÓN B: Editor de Texto
--------------------------
1. Abre GameServer.rc con Notepad++
2. Busca la sección que dice "DIALOG" o "DIALOGEX"
3. Ve al final de esa sección (antes de STRING TABLE)
4. Copia y pega los dos diálogos de arriba
5. Guarda el archivo

================================================================================
CONTROLES USADOS:
================================================================================

Diálogo de Configuración:
- 4 Checkboxes (Enable, AutoCheck, AutoDownload, ShowNotifications)
- 2 Edit boxes (URL, Version)
- 2 Botones (Save, Cancel)
- 3 GroupBoxes (para organizar visualmente)
- Labels informativos

Diálogo de Progreso:
- 1 Icon (icono del GameServer)
- 1 Progress Bar (barra de progreso animada)
- 3 Labels dinámicos (FileName, Progress %, Size)
- Labels estáticos

================================================================================
VERIFICACIÓN:
================================================================================

Después de agregar los diálogos:

1. Rebuild el proyecto
2. Si hay errores, verifica:
   - Los IDs están definidos en resource.h ✓
   - La sintaxis del .rc es correcta
   - No hay IDs duplicados

3. Prueba los diálogos:
   - Update → Config Updates (abre configuración)
   - Update → Check for Updates (muestra progreso al descargar)

================================================================================
NOTA: 
Si prefieres, puedo crear estos diálogos de manera programática (sin .rc)
usando CreateWindowEx, pero el método .rc es más estándar y fácil de mantener.
