DEFINED SAFE ZONES:

Map 3  - Noria     (150-200, 100-160) [Newbie Zone]
Map 51 - Elveland  (40-90, 180-230)   [Newbie Zone]
Map 1  - Elbeland  (Entire map)

SAFE ZONE FUNCTIONS:
────────────────────
IsSafeZone(mapNumber)
  → Quick check if map is safe

IsInSafeZoneArea(mapNumber, x, y)
  → Check if coords are in safe area

SafeZoneWander(aIndex)
  → Make bot walk randomly in safe zone
  → Uses MoveRange as radius
  → Creates natural walking pattern

MoveBotToRandomNearbyPoint(aIndex, radius)
  → Move bot to random point within radius
  → Uses pathfinding (gPath.FindPath)
  → Checks for walls

HOW WANDERING WORKS:
────────────────────
1. Bot is in safe zone (e.g., Lorencia)
2. Call SafeZoneWander(botIndex) every 5-10 seconds
3. Picks random point within MoveRange
4. Walks there using pathfinding
5. Repeats → bot walks around naturally!

Example:
  Merchant at (104, 190), MoveRange=50
  → Walks to (130, 200)
  → Walks to (95, 185)
  → Walks to (115, 195)
  → Continues wandering...

✅ NOW:    Bots WALK AROUND like real players!
