WHAT WAS THE PROBLEM?
================================================================================

PROBLEM 1: Placeholders not being replaced in bot chat responses
- ReplaceTradePlaceholders was commented out in ChatRecv function
- Bots would say "{item_required}" literally instead of "Jewel of Life"

PROBLEM 2: Trade window messages were generic
- Message said: "Put the required items and press OK!"
- Didn't tell player WHICH items were needed

PROBLEM 3: GetItemName was private
- BotTrader.cpp couldn't use it to show item names in trade messages

FILE 3: /workspace/GameServer/BotTrader.cpp
-------------------------------------------
CHANGE: Trade opening message now shows actual item names (line ~678)

The code was already there from previous fix! It builds item names like:
```cpp
// Build required items message with item names
std::string requiredMsg = "";
for (size_t i = 0; i < config.requiredItems.size(); i++) {
    if (i > 0) requiredMsg += " + ";
    requiredMsg += s_FakeOnline.GetItemName(config.requiredItems[i].Type);
}

// Build reward items message with item names
std::string rewardMsg = "";
for (size_t i = 0; i < config.rewardItems.size(); i++) {
    if (i > 0) rewardMsg += " + ";
    rewardMsg += s_FakeOnline.GetItemName(config.rewardItems[i].Type);
}

// Send notice with actual item names
char tradeMsg[256];
sprintf_s(tradeMsg, sizeof(tradeMsg), "%s: Need %s, will give %s. Put items and press OK!", 
    lpBot->Name, requiredMsg.c_str(), rewardMsg.c_str());
gNotice.NewNoticeSend(lpObj->Index, 0, 0, 0, 0, 0, tradeMsg);
```

HOW IT WORKS NOW
================================================================================

SCENARIO: Bot "ricardo" trades Jewel of Life for Jewel of Creation

1. Bot randomly says trade phrases while walking around:
   - "Need Jewel of Life, have Jewel of Creation!"
   - "Looking for Jewel of Life, trade me!"
   - "WTB: Jewel of Life = Jewel of Creation"
   - "Quick trade: Jewel of Life -> Jewel of Creation"

2. Player talks to bot, bot responds:
   - Player: "trade"
   - Bot: "I need Jewel of Life, I can give you Jewel of Creation!"

3. Player clicks to trade:
   - Message: "ricardo: Need Jewel of Life, will give Jewel of Creation. Put items and press OK!"
   - Bot's items (Creation jewel) are visible in trade window ✅
   - Player can see exactly what bot wants and what bot offers ✅

4. Player adds Jewel of Life and presses OK:
   - Trade validates and completes
   - Player receives Jewel of Creation
   - Bot receives Jewel of Life

================================================================================
AVAILABLE PLACEHOLDERS
================================================================================

{item_required}  - Shows the item(s) bot wants from player
                   Example: "Jewel of Life" or "Jewel of Life + Jewel of Soul"

{item_reward}    - Shows the item(s) bot will give to player
                   Example: "Jewel of Creation" or "Wing+9 Exc"

{player_name}    - Shows the player's name
                   Example: "Hello Steve!"
