COMMON QUESTIONS:
=================

Q: Why do we need to drop and recreate primary keys?
A: SQL Server doesn't allow changing column type when it's part of a constraint.
   We must drop the constraint first, change the column, then recreate it.

Q: Will I lose data?
A: NO! The data is preserved. Only the data TYPE changes (varchar → nvarchar).
   Primary keys are recreated with the same structure.

Q: What if I have custom tables?
A: The script handles optional tables (ChatLog, MemoData, PersonalShop).
   For your custom tables, add similar ALTER TABLE statements.

Q: Do I need to restart GameServer?
A: YES! After database migration, restart GameServer with the Unicode-enabled
   version (that you compiled earlier).
