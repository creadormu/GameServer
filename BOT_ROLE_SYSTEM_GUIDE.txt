The Create Bots dialog will have a NEW section:

┌─ Bot Roles (Distribution) ────────────────────────┐
│                                                    │

│  Merchant:  [____20____]%                         │

│  Total must equal 100%                            │
│                                                    │
│  Example: Creating 100 bots                       │
│    • 70 will be Warriors (combat)                │
│    • 20 will be Merchants (trading)              │
│    • 10 will be Friendly (helpers)               │
│                                                    │
└────────────────────────────────────────────────────┘

HOW IT WORKS:
1. User enters bot percentages
2. System validates total = 100%
3. When creating bots, assigns roles based on %
4. Example: 50 bots, 80/10/10 split:
   - First 40 bots = WARRIOR
   - Next 5 bots = MERCHANT
   - Next 5 bots = FRIENDLY

                        MERCHANT BOT - DETAILED BEHAVIOR
═══════════════════════════════════════════════════════════════════════════

MERCHANT FLOW:

1. INITIALIZATION
   ├─ Spawn in safe zone (Lorencia/Devias/Noria)
   ├─ Load FakeBotTrade.txt for available trades
   └─ Start advertising timer

2. SAFE ZONE LOOP (80% of time)
   ├─ Walk around town (50 tile radius)
   ├─ Every 2-5 minutes: Send advertisement
   │  └─ "Trading {required_jewel} for {reward_jewel}!"
   ├─ Respond to players who say "trade"
   ├─ Check inventory + jewel bank for jewels
   └─ After 15 minutes in safe zone → Go hunting

3. HUNTING PHASE (20% of time)
   ├─ Go to nearby hunting zone
   ├─ Hunt monsters (focus on jewel drops)
   ├─ Pick up jewels automatically
   ├─ Store jewels in jewel bank when full
   ├─ After 10-15 minutes → Return to safe zone
   └─ Resume advertising

4. TRADING INTERACTION
   ├─ Player says "trade" or "/trade"
   ├─ Bot responds: "What do you need?"
   ├─ Player opens trade
   ├─ Bot shows FakeBotTrade options
   ├─ Player puts required jewels
   ├─ Bot checks trade validity
   ├─ Bot gives reward jewels (from inventory or bank)
   ├─ Trade completes
   └─ Bot says: "Thanks for the trade!"

ADVERTISEMENT PLACEHOLDERS:
  {required_jewel} = Jewel needed (e.g., "Soul")
  {reward_jewel}   = Jewel given (e.g., "Bless")
  {trade_name}     = Trade name from config

EXAMPLE ADVERTISEMENTS:
  • "Trading Soul for Bless!"
  • "Need Chaos? I have it! Bring Life!"
  • "Best jewel exchange: Soul → Bless!"
  • "Trading Life for Chaos! Fair prices!"

3. HELP INTERACTION
   ├─ Player says "help" or "where is X"

   ├─ Offers to show the way
   ├─ If accepted, moves near player
   ├─ Gives directions or tips
   ├─ Encourages: "You're doing great!"

4. PARTY SUPPORT
   ├─ Detects low-level players (< level 150)
   ├─ Sends party invite
