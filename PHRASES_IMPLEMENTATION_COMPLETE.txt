Answering.txt contains:

#GREETING             → Responds to: hello, hi, hey

#GOODBYE              → Responds to: bye, see you
#LEVEL                → Responds to: level, lvl
#LOCATION             → Responds to: where, map
#THANKS               → Responds to: thanks, thx

═══════════════════════════════════════════════════════════════════════════
                     USAGE INSTRUCTIONS
═══════════════════════════════════════════════════════════════════════════

STEP 1: COMPILE
───────────────
1. Add to Visual Studio project:
   - PhraseManager.h
   - PhraseManager.cpp

2. Build Solution (Ctrl+Shift+B)

STEP 2: DEPLOY FILES
────────────────────
Copy IA/ folder structure:
  IA/
  ├── Names/
  │   ├── Spanish/
  │   ├── English/
  │   └── ...
  ├── Phrases/
  │   ├── Spanish/
  │   │   └── BotPhrases.txt
  │   ├── English/
  │   │   └── BotPhrases.txt
  │   └── ...
  └── Answers/
      ├── Spanish/
      │   └── Answering.txt
      ├── English/
      │   └── Answering.txt
      └── ...

STEP 3: START SERVER
────────────────────
Check console for:
  [NameManager] Loaded language: Spanish (50 male, 40 female names)
  [PhraseManager] Loaded language: Spanish (Phrases: OK, Answers: OK)

STEP 4: SELECT LANGUAGE
───────────────────────
1. Open IA → Create Multiple Bots
2. Select language: English, Spanish, Chinese, etc.
3. Console shows:
   [Language] Changed to: English (Names: OK, Phrases: OK)
   [Language] Bot phrases and answers reloaded

STEP 5: CREATE BOTS & TEST
──────────────────────────
1. Create bots
2. Watch bots speak in chat!
3. Try talking to them (they respond to keywords)
4. Party with them (they say party phrases)
5. Fight them (they say PVP phrases)
