================================================================================
  INSTALLATION - 3 SIMPLE STEPS (30 minutes)
================================================================================

STEP 1: BACKUP (5 minutes) - CRITICAL!
=======================================
1. Open SQL Server Management Studio
2. Right-click MuOnline database → Tasks → Back Up
3. Save backup file somewhere safe
4. Copy your entire GameServer folder to GameServer_Backup

STEP 2: UPDATE DATABASE (10-25 minutes)
========================================
1. Open SQL Server Management Studio
2. Connect to your server
3. Open file: Database_Unicode_Migration.sql
4. Click Execute (F5)
5. Wait for completion (10-25 minutes depending on database size)
6. You should see: "Unicode Migration Completed Successfully!"

7. Open file: Database_StoredProcedure_Unicode_Update.sql
8. Click Execute (F5)
9. Wait for completion (< 1 minute)
10. You should see: "Stored Procedures Updated Successfully!"

STEP 3: UPDATE GAMESERVER (5 minutes)
======================================
1. Open GameServer project in Visual Studio
2. Add new files to project:
   - Right-click project → Add → Existing Item
   - Select: UnicodeSupport.h
   - Select: UnicodeODBC.h
   - Select: UnicodeFileIO.h

3. Open stdafx.h
4. Add at the very end:
   
   // Unicode support for multilingual characters
   #include "UnicodeSupport.h"
   #include "UnicodeODBC.h"
   #include "UnicodeFileIO.h"

5. Build → Rebuild Solution (Ctrl+Shift+B)
6. Fix any compile errors (should be none!)
7. Copy GameServer.exe to your server folder

THAT'S IT! Now test...

================================================================================
  TROUBLESHOOTING
================================================================================

PROBLEM 1: Characters still show as "???"
------------------------------------------
CAUSE: Database not converted
FIX: Re-run Database_Unicode_Migration.sql
     Make sure it says "Completed Successfully!"

PROBLEM 2: GameServer won't compile
------------------------------------
CAUSE: Headers not found
FIX: Make sure UnicodeSupport.h, UnicodeODBC.h, UnicodeFileIO.h 
     are in GameServer folder
     Make sure you added #include in stdafx.h

PROBLEM 3: Can't create character with Portuguese name
-------------------------------------------------------
CAUSE: Stored procedures not updated
FIX: Run Database_StoredProcedure_Unicode_Update.sql
     Should say "Stored Procedures Updated Successfully!"

PROBLEM 4: Existing characters can't login
-------------------------------------------
CAUSE: Database migration issue
FIX: Restore backup and try again
     OR contact support with error message

PROBLEM 5: Chat messages truncated
-----------------------------------
CAUSE: Byte-level truncation
FIX: Not a problem! This is expected.
     Portuguese uses 2 bytes for accents
     So 60-byte limit = ~40-50 Portuguese characters

================================================================================
  NOW YOU CAN USE UNICODE
================================================================================

When you want to update your code to use Unicode functions:

EXAMPLE 1: Create character with Unicode name
----------------------------------------------
CUnicodeODBC db;
db.Connect("localhost", "MuOnline");

char query[256];
sprintf_s(query, "INSERT INTO Character (Name) VALUES (N'%s')", "João");
db.ExecuteQuery(query);

db.Disconnect();

EXAMPLE 2: Validate chat message
---------------------------------
if (!IsValidUTF8(message))
    return; // Invalid message

TruncateUTF8(message, 60); // Safe truncation

EXAMPLE 3: Check name length
-----------------------------
size_t charCount = UTF8Length(name); // Characters, not bytes!
if (charCount < 3 || charCount > 10)
    return false; // Invalid length

EXAMPLE 4: Read config file with Unicode
-----------------------------------------
std::vector<std::string> lines;
ReadUTF8File("config.txt", lines);

for (const auto& line : lines)
{
    // Process line with UTF-8 text
}

See UnicodeODBC_Example.cpp for more examples!

CHARACTER LIMITS:
-----------------
- Character names: 10 characters (not bytes!)
  Example: "João" = 4 characters, 5 bytes ✅
  Example: "Testplayer" = 10 characters, 10 bytes ✅

- Chat messages: 60 bytes maximum
  English: ~60 characters
  Portuguese: ~40-50 characters (accents use 2 bytes)
  Chinese: ~20 characters (3 bytes each)
