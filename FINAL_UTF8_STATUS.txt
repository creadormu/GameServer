================================================================================
  📝 MAINTENANCE NOTES
================================================================================

For Future Developers:

1. **Adding new player-visible text?**
   → Use sprintf_s, NOT wsprintf!
   → Always add sizeof() for safety

2. **Loading text files?**
   → Use ReadUTF8File() from UnicodeFileIO.h
   → Save files as UTF-8 (with BOM recommended)

3. **Database text columns?**
   → Use NVARCHAR, NOT VARCHAR
   → Use CUnicodeODBC class for queries

4. **String conversions?**
   → UTF8ToUTF16() for ODBC
   → UTF16ToUTF8() for return values
   → See UnicodeSupport.h

5. **Client shows symbols?**
   → Check chat bubble first
   → If bubble works = server correct
   → If log fails = client bug
