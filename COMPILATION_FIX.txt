IF YOU STILL GET ERRORS:
========================

ERROR: "Cannot open include file: 'sql.h'"
------------------------------------------
CAUSE: Windows SDK not installed or path not configured
FIX: 
  1. Install Windows SDK
  2. Or check Project Properties → Configuration Properties → 
     VC++ Directories → Include Directories
  3. Should include: $(WindowsSdkDir)Include

ERROR: "Unresolved external symbol SQL..."
------------------------------------------
CAUSE: ODBC libraries not linked
FIX: Already fixed in stdafx.h with pragma comment
     If still occurs, manually add in:
     Project Properties → Linker → Input → Additional Dependencies
     Add: odbc32.lib;odbccp32.lib

ERROR: "Redefinition of SQLWCHAR"
---------------------------------
CAUSE: Multiple includes of sql.h
FIX: Make sure you DON'T include <sql.h> or <sqlext.h> 
     in any other .cpp or .h files
     They are now in stdafx.h

ERROR: "g_hOdbcConn undeclared identifier"
------------------------------------------
CAUSE: Example files reference global variable
FIX: The example files (UnicodeODBC_Example.cpp, ChatUnicode_Example.cpp)
     are EXAMPLES ONLY - they show you how to write code
     You should NOT add them to your project yet
     Only add UnicodeSupport.h, UnicodeODBC.h, UnicodeFileIO.h
